# Pastel 20261109.1 · macOS 15 适配版

同步上游截至 `016aa1e`（2026-11-09）的更新，保留本 fork 的 macOS 15.0+ / Apple 芯片支持。

- 引入上游新的 Apple 认证与下载组件，修复旧认证流程失效、并发下载和首次获取免费 App 时反复要求登录的问题。
- 将 store-helper 从源码重新构建为 macOS 15.0 arm64；构建与打包会检查 App、Node、SAP signer、helper 的最低系统版本。
- 保留 macOS 15 外观兼容与悬停提示防崩溃封装，修正合并时的 Xcode 文件标识冲突。
- 保留会话保存失败不能显示登录成功、取消后忽略旧回调，以及普通 403 不触发反复登录的处理。
- 登录界面显示准备、认证等阶段；合入新的验证码界面和 Debug 隔离模拟。
- 保持本 fork 的 Releases 更新入口，不恢复上游 Sparkle 更新源。
- 新增项目级 AGENTS.md，记录后续同步上游时的兼容、构建、认证和验证约束。

上游认证会话格式已更新，升级后需要重新登录，首次使用可能需要下载认证运行时。真实 Apple 登录、验证码及授权 IPA 下载需要在 App 中完成验证；离线测试不能替代实际账户验证。

本地验证（macOS 15.7.3 / Xcode 26.2）：Debug 和 Release 构建通过；71 项 Node 测试、Go 竞态测试、16 项 Swift 元数据用例及隔离登录状态测试通过；认证模拟执行引擎可运行；DMG 校验、签名和最低系统版本检查通过。已启动新版进程，尚未完成实际账户登录与下载验证。
